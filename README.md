# Análise Estatística dos Dados CGIL/CNIg de 2024 e 2025

## Sobre o projeto

Este repositório apresenta um trabalho de análise estatística desenvolvido em R, utilizando dados da Coordenação Geral de Imigração Laboral (CGIL) e do Conselho Nacional de Imigração (CNIg), referentes aos anos de 2024 e 2025.

O objetivo é analisar informações relacionadas à imigração laboral no Brasil, com foco nos registros de profissionais qualificados, considerando características educacionais, nacionalidade, distribuição geográfica e modalidades de autorização de residência.

## Objetivo

Realizar uma análise descritiva dos dados de imigração laboral, identificando padrões e diferenças entre os períodos estudados, por meio de tabelas, gráficos e indicadores estatísticos.

## Base de dados

Foram utilizadas bases de dados referentes aos anos de 2024 e 2025, disponibilizadas em formato CSV.

Os dados foram tratados e organizados no R para permitir a comparação dos períodos e a construção das análises apresentadas no relatório.

## Metodologia

O trabalho foi desenvolvido utilizando a linguagem R e o ambiente RStudio.

As etapas compreenderam a importação das bases de dados, a organização das variáveis, a aplicação de critérios de classificação, a elaboração de tabelas de frequência e a construção de gráficos.

As análises consideram recortes trimestrais e características dos registros, conforme os critérios metodológicos descritos no relatório.

## Arquivos do repositório

**trabalho.Rmd**

Arquivo principal contendo os códigos em R, as análises estatísticas e as interpretações dos resultados.

**trabalho.html**

Relatório gerado a partir do arquivo R Markdown, contendo as tabelas, os gráficos e as conclusões do estudo.

**dados.Rproj**

Arquivo do projeto utilizado no RStudio.

## Ferramentas utilizadas

R, RStudio, R Markdown e GitHub.

## Considerações finais

O projeto busca contribuir para a compreensão do perfil da imigração laboral qualificada no Brasil nos períodos analisados.

Os resultados são apresentados de forma descritiva, respeitando os critérios de tratamento e classificação adotados no trabalho. Eventuais diferenças em relação aos valores de referência são discutidas no relatório.
